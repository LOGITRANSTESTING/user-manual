## Pre defined conditions

@11 Empty Return Location cannot be Empty

## Steps
**Step 1:** Enter the required query parameters in the search fields and click on {img:img/How_to_Generate_Empty_Return_Advice_01.png}.
**Step 2:** Upon clicking {img:img/How_to_Generate_Empty_Return_Advice_02.png}, BL records matching the entered criteria will be returned in the data grid.
**Step 3:** Select the desirable record(s) by either clicking on {img:img/How_to_Generate_Empty_Return_Advice_03.png} select all checkbox or {img:img/How_to_Generate_Empty_Return_Advice_04.png} individual selection individual selection checkbox of the respective BL.
**Step 4:** Click on the {img:img/How_to_Generate_Empty_Return_Advice_05.png} icon (Voyage level) and then select **Empty Return Advice - GR** function from the menu. This will open the **Empty Return Advice - GR** screen.
![](img/How_to_Generate_Empty_Return_Advice_06.png)

If process is successful, the generated Empty return advice will be shown as a pdf andsuccess message is shown as given below.
