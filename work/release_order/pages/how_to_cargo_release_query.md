## Steps
**Step 1** : Enter the query fields with desirable input for querying data and click on {img:../img/crq_btn_search.png}.
![](../img/crq_01.png)
**Step 2** : Upon clicking {img:../img/crq_btn_search.png}, BLs with matching information are returned.
**Step 3** : The user should drag the cursor to the record menu icon {icon:record_menu} in the respective record, click on it, and then select "**Cargo Release Query**" from the menu.
![](../img/crq_03.png)
**Step 4** : Upon clicking "**Cargo Release Query**", User will be shown the Cargo Release Query screen with the Release Order details of the respective BL as shown below.
![](../img/crq_04.png)
