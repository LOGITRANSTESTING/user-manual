## Steps
**Step 1** : Enter the query fields with desirable input for querying data and click on {img:../img/btn_search.png}.
![](../img/hc_01.png)
**Step 2** : Upon clicking {img:../img/btn_search.png}, BLs with matching information are returned.
**Step 3** : Click on "**Not Generated**" in the toggle to view the BLs that do not have existing Release Orders.
**Step 4** : The user should drag the cursor to the record menu icon {icon:record_menu} in the respective record, click on it, and then select "**Hold Container**" from the menu.
![](../img/hc_02.png)
**Step 5** : Upon clicking "**Hold Container**", the user is shown Hold Container pop up screen with the containers of the BL.
**Step 6** : Select the checkbox {img:../img/cb_single_select.png} of the container(s) to be put on hold.
**Step 7** : Enter the reason for holding the container(s) in the **Remarks** field.
**Step 8** : Click on {img:../img/hc_btn_submit.png}.
![](../img/hc_03.png)
If successfully processed, a success message is shown as given below.
![](../img/hc_04.png)
