## Steps
**Step 1** : The user should drag the cursor to the record menu icon {icon:record_menu} in the respective record, click on it, and then select "**AMS Web**" from the menu.
![](../img/ams_web_01.png)
**Step 2** : Upon clicking "**AMS Web**" the user is shown AMS Web pop up screen.
![](../img/ams_web_02.png)
