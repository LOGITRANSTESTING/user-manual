## Steps
**Step 1** : The user should drag the cursor to the batch function menu icon {icon:batch_menu}, click on it, and then select "**BL EDI Communication History [TW]**" from the menu.
![](../img/bl_edi_01.png)
**Step 2** : Upon clicking "**BL EDI Communication History [TW]**" User will be shown the BL EDI Communication History [TW] screen.
**Step 3** : Enter the query fields with desirable input for querying data and click on {img:../img/btn_search.png}.
![](../img/bl_edi_02.png)
**Step 4** : Upon clicking {img:../img/btn_search.png}, BL records with matching information are returned.
**Step 5** : Either select all BL records available by clicking on {img:../img/chk_select_all.png}(select all checkbox) or select individual BL records by clicking on {img:../img/chk_single.png}(single select checkbox).
**Step 6** : Click on {img:../img/btn_regenerate.png}.
![](../img/bl_edi_03.png)
If successfully regenerated, a success message is shown as given below.
![](../img/bl_edi_04.png)
