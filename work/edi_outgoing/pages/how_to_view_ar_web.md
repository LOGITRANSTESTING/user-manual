## Steps
**Step 1** : The user should drag the cursor to the record menu icon {icon:record_menu} in the respective record, click on it, and then select "**AR Web**" from the menu.
![](../img/ar_web_01.png)
**Step 2** : Upon clicking "**AR Web**" the user is shown AR Web pop up screen.
![](../img/ar_web_02.png)
