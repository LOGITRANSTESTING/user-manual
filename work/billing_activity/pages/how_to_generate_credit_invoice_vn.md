## Steps
**Step 1** : Click on the {img:../img/vn_icon_side.png} (Single Invoice side icon) given on the right side of the Billing Activity screen.
![](../img/vncash_01.png)
**Step 2** : Upon clicking {img:../img/vn_icon_side.png}, User will be shown the Single Invoice screen.
**Step 3** : Enter the query fields with desirable input for querying data and click on {img:../img/vn_btn_search.png}.
![](../img/vnc_02.png)
**Step 4** : Upon clicking {img:../img/vn_btn_search.png}, the BL details and charges with matching information are returned.
**Step 5** : Select the required Settlement Type and Charge Type.
**Step 6** : Either select all charges available by clicking on {img:../img/vn_cb_all.png}(select all checkbox) or select individual charges by clicking on {img:../img/vn_cb_single.png}(single select checkbox).
**Step 7** : Click on {img:../img/vn_btn_credit_invoice.png}.
![](../img/vnc_03.png)
**Step 8** : Upon clicking {img:../img/vn_btn_credit_invoice.png}, the user is shown Credit Invoice pop up screen.
**Step 9** : Enter the details as given below and click on {img:../img/vn_btn_check_list.png}.
![](../img/vnc_04.png)
If successfully validated, a success message is shown as given below.
**Step 10** : Click on {img:../img/vn_btn_process.png}.
![](../img/vnc_05.png)
If successfully processed, an alert with the System Generated Invoice Number is shown as given below.
**Step 11** : Click on {img:../img/vn_btn_ok.png}.
![](../img/vnc_06.png)
**Step 12** : Upon clicking {img:../img/vn_btn_ok.png}, User will be shown the Tax Invoice Generation screen with the File Path auto populated.
**Step 13** : Click on {img:../img/vn_rb_generate.png}(Generate radio button).
**Step 14** : Either select all invoices available by clicking on {img:../img/vn_tig_cb_all.png}(select all checkbox) or select individual invoices by clicking on {img:../img/vn_tig_cb_single.png}(single select checkbox).
**Step 15** : Click on {img:../img/vn_btn_process_tig.png}.
![](../img/vnc_07.png)
If successfully processed, a success message is shown as given below.
![](../img/vnc_08.png)
