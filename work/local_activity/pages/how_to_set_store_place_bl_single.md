## Steps
**Step 1** : Enter the query fields with desirable input for querying data and click on {img:../img/btn_search.png}.
**Step 2** : Upon clicking {img:../img/btn_search.png}, BLs with matching information are returned.
**Step 3** : The user should drag the cursor to the record menu icon {icon:record_menu} in the respective record, click on it, and then select "**Set Store Place [BL]**" from the menu.
![](../img/spb_01.png)
**Step 4** : Upon clicking "**Set Store Place [BL]**" User will be shown the Set Store Place [BL] screen.
**Step 5** : Select the {img:../img/sps_radio_container_type.png} radio button.
**Step 6** : Click on {img:../img/btn_add.png} to add a new row.
**Step 7** : Enter all the necessary fields in the row. "**Container Type**" and "**Store Place**" fields are mandatory.
**Step 8** : Click on {img:../img/btn_submit.png}.
![](../img/spb_02.png)
If successfully submitted, a success message is shown as given below.
![](../img/spb_03.png)
